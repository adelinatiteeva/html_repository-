# OneDayIn Static Catalog

A lightweight static site for the OneDayIn city catalog showcasing 20 partner places per city.

## Getting started

1. Download or clone this folder.
2. Open `index.html` directly in a browser (double-click the file), **or** run a simple server:

```bash
python -m http.server
```

Then visit [http://localhost:8000](http://localhost:8000) in your browser.

The site has no external dependencies and works fully offline using the embedded data fallback.
