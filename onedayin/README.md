# OneDayIn Catalog

A static marketing site for the OneDayIn city catalog with dynamic city/offers rendering, theme toggle, and lead capture modal.

## Getting started

1. Download or clone this repository.
2. Open the `onedayin/index.html` file directly in your browser (double-click it), **or** run a simple server:

```bash
cd onedayin
python -m http.server 8000
```

3. Visit <http://localhost:8000> in your browser.

No external dependencies are required.
